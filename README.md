# Steward FX

Steward FX is the intelligence and control layer for onchain currency operations. It traces a stablecoin conversion from business obligation and current balances through policy, authorization, atomic settlement, and reconciliation.

This repository currently contains the public product site and an illustrative workflow. StableFX access has been requested; the site does not represent a live Circle integration or endorsement.

## Local development

```sh
npm install
npm run dev
```

## Production build

```sh
npm run build
```
